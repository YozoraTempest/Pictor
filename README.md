# Pictor

Pictor 是一个面向 Agent 委托工作流的桌面开发环境。当前首期目标是在 Windows 11 上完成
本地项目、持久化 Session、流式 Agent 对话、命令审批和基础模型设置的最小闭环。

## 开发环境

- Windows 11
- Node.js 22 或更新版本
- Git for Windows

## 常用命令

```powershell
npm install
npm run dev
npm run typecheck
npm run lint
npm test
npm run test:e2e
npm run build
npm run package:dir
```

当前仓库仍处于 MVP 开发阶段，功能与持久化格式尚未形成兼容承诺。
