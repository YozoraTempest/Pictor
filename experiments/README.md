# Experiments

代码放这里，**不参与构建、不进工作区、不跑测试**：`pnpm-workspace.yaml` 只收
`apps/*`、`packages/*`、`plugins/*`。

放进来意味着"这条路当前不走，但留着看得见"——不是备份，也不是待办。要再用，先把它
移回 `packages/`，再补依赖与别名。

| 目录           | 是什么                                                                                          | 为什么在这                                                                           |
| -------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `kernel-pi/`   | Pi（`pi --mode rpc`）作为第二个引擎的完整实现：RPC 驱动、事件投影、历史、独立配置目录、审批扩展 | 这一版只有 dsh 一个引擎（`DshHarness` 直连 dsh），换引擎的机制连同它的界面一起拆掉了 |
| `fake-kernel/` | 一个只会回声的"内核插件"，把 `provideKernel` 的写法当样例                                       | 同上：应用不再接受插件提供的引擎，这个样例没有安装路径了                             |
